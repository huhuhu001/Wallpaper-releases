# Wallpaper · 官方更新源

本仓库**只用于发布 Wallpaper 客户端的更新包**，不含、也不会包含任何源码。

## 这是什么

- Wallpaper 是一款**本地离线**的 Windows 桌面工具:从「人物 / 主题」三层素材库惰性取图,
  经 AI 主体检测避让 + SkiaSharp 合成后,按定时 / 快捷键 / 托盘三种方式自动替换桌面壁纸。
- AI 推理与图像合成全部在本机 CPU 完成,**图片不会上传**;程序默认不联网。
- 客户端为**免安装**形态:解压即用,整个目录就是程序本体。

## 下载

在右侧 **Releases** 选择最新版本,下载其中的 `Wallpaper-<版本号>-win-x64.zip`,
解压到**本地固定目录**(不要放在 OneDrive / 网络盘 / 压缩包内直接运行)后运行 `Wallpaper.exe` 即可。

每个 Release 附带两个文件:

| 文件 | 用途 |
| --- | --- |
| `Wallpaper-<版本号>-win-x64.zip` | 客户端更新包(解压即可用) |
| `SHA256SUMS.txt` | 更新包校验清单,客户端更新时自动比对,防止下载被篡改或截断 |

## 更新方式

客户端内置「设置 → 关于 → 检查更新」:

- **默认不联网**,只有你主动点击(或自行开启启动检查)时才会访问 GitHub 官方更新源;
- 下载更新包后先做 SHA256 校验,再以「双目录原子替换」方式换新,失败不会损坏现有程序;
- 除更新源请求外无任何网络行为,无账号、无遥测,不上传任何图片或个人数据。

## 运行要求

- Windows 10 / 11(x64)
- 非自包含版本需安装 .NET 8 运行时
